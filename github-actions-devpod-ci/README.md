# GitHub Actions DevPod CI

A demonstration project for building a CI pipeline using GitHub Actions
with development performed inside a DevPod Docker environment.

## Application

This project contains a small Python calculator module with automated tests.

## Development Environment

- DevPod
- Docker
- Mise
- Git
- Python

## CI

GitHub Actions will be used to:

1. Set up the required tools
2. Install dependencies
3. Run linting
4. Run automated tests
5. Build/validate the application
